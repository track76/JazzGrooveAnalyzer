# Jazz Groove Analyzer

Research software for double-bass attack analysis from full mixes. **BLOCKED_REFERENCE; conditional PhaseB NOT_STARTED.** Technical/synthetic results do not validate physical string excitation.

For a programmer's first read-only review: [review entry](docs/review/PROGRAMMER_REVIEW.md), [scientific checkpoint](docs/review/SCIENTIFIC_STATUS.md), [architecture reading map](docs/review/ARCHITECTURE.md), [Core/Domain draft](docs/architecture/CORE_DOMAIN_BOUNDARY.md), src/jga, pyproject.toml and requirements.txt.

The latest synthetic contrast detects weak added components but also responds strongly to gain changes, pitch glide and masking, with excessive extra crossings; no winning detector is promoted. A qualified independent physical reference with rights/consent, linkage, clock and uncertainty remains necessary. Acoustic onset, MIDI/sample time and physical gesture are different.
