## Frozen decision

The current Bass-recovery / Bass-observability research branch is closed. The
accepted synthesis establishes that the existing CED datasets and authorized
representations do not support a Ground-Truth-independent, source-specific and
timing-valid production recovery rule.

No additional experiment, spectral feature, threshold tuning, classifier,
composite score, source-attribution rule or production modification is
authorized from the current evidence.

## Reopening condition

Reopening requires genuinely new scientific evidence or authority that changes
the present source-attribution or timing authority. Legitimate paths include:

- an independent, provider-authoritative common-clock multitrack dataset;
- JTD, if access and provenance support the required source-specific temporal
  authority;
- prospectively frozen materially improved source-separation technology;
- independently justified temporal or source priors not derived from current
  CED outcomes;
- controlled physical-acoustic recordings with overlapping-source and negative
  controls; or
- an independent evidence modality with explicit alignment and provenance.

Merely recomputing, thresholding or reducing the existing spectral evidence is
not a reopening condition.

This freeze changes no scientific result, fingerprint, checksum, production
code or architecture.
