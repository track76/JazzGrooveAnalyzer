## Frozen design

- Training: paired recordings of drummers1,3,4,5,6. Calibration: drummer7. Held-out development evaluation: drummers8,9,10. Whole drummers/sessions stay separate. Do not use the supplied musical split/style/tempo fields. Do not move groups after seeing results.
- Observation opportunity: positive-velocity MIDI note-on (or original MDB subclass annotation later). Keep a 250 ms crop centred at its authority timestamp only when no OTHER annotated note-on lies in that crop and the complete crop lies within WAV support. This is an onset-contamination eligibility rule, not a regularity feature. It does NOT establish absence of previous acoustic tails. Preserve exclusions by reason and subtype. No onset detector, listening, label repair, separation or synthetic augmentation.
- Training cap: at most 250 eligible events per drummer/native subtype, chosen by SHA-256 of the stable dataset/event ID. This is a resource cap, not a statistical sufficiency requirement. Calibration and held-out evaluation use ALL eligible events. Retain full available/eligible/selected counts. Training class weights balanced; evaluation prevalence unaltered within eligible population.
- Representation: mono channel mean; resample to 44,100 Hz if needed with scipy polyphase resampling. Crop 11,025 samples centred by nearest sample. Divide by crop RMS (exact zero => unresolved). 2,048-sample periodic Hann STFT, hop441, zero-pad1,024 each end; 26 frames. 32 Slaney-normalized mel bands20–20,000Hz. `log1p(mel_magnitude)`, flattened32×26. All are prospective engineering choices. No long-context recurrent model or feature search.
- StandardScaler fitted on training only; LogisticRegression C=1, balanced classes, lbfgs, max_iter2000, tol1e-6. No hyperparameter search. Convergence failure stops; no post-result repair. Thread limits1 for bounded repeatability.
- Ordinary probe rule p>=0.5 (conventional equal-cost diagnostic boundary, not a confidence guarantee). Calibrated selective rule: high=max(0.5,nextafter(max negative calibration score,+infinity)); low=min(0.5,nextafter(min positive calibration score,-infinity)). At/above high => RIDE_COMPATIBLE; at/below low => NOT_RIDE_COMPATIBLE; otherwise ABSTAIN. This operationally avoids observed calibration false admissions/rejections; it does not guarantee error rates elsewhere. If a calibration class is absent, stop with insufficient evidence. Unresolved extraction is not negative.
- Report precision/recall, AP with prevalence baseline, ROC AUC, balanced accuracy, entire PR curve and selective errors/coverage, per-subtype counts and per-recording metrics. No naive independent-hit confidence interval. No significance or population guarantee from a finite held-out sample.
- Technical-viability gate, NOT high-confidence sufficiency: both classes available, fit converged, held-out development balanced accuracy>0.5 AND AP>held-out Ride prevalence, both against all negatives and within the Ride-versus-Hi-Hat subset. These are simple reference-performance checks, not a validated admission threshold. Gate failure => GMD_DISCRIMINATION_INSUFFICIENT; missing authority/classes => INSUFFICIENT_EVIDENCE; invalid computation => INDETERMINATE. Preserve result; no alternate model.
- If gate succeeds, emit GMD_DISCRIMINATION_WORKS and freeze model, scaling, selective thresholds, implementation/protocol/input/environment hashes. No refitting on calibration or development evaluation. MDB mode must reject absent/mismatched freeze. Write all GMD outcomes BEFORE MDB is opened.
- MDB: one application of the exact frozen pipeline to all 23 acquired original drum-only files and original annotations, using the SAME complete-window/no-other-onset eligibility rule. RDC/RDB positive; HH subtypes negative; all other native annotations controls. No mapping RDC to bow. Preserve excluded overlap opportunities. The primary claim concerns this eligible subset of real performances, not every event or concurrent-hit performance. Same descriptive viability rule categorizes bounded transfer WORKS/FAILS; report selective results separately, never claim high confidence solely from this gate. No change after opening MDB.

## Authorities, limits, preservation

Capture/provider annotation, predictor and evaluator roles are distinct data paths. Predictions consume only waveform patches; scoring joins immutable labels. This is a single-assistant implementation, not independent human review. Synthetic checks cover patch shape, gain invariance, mapping and eligibility; input hashes/header/timestamp checks precede features. No new independently staffed reviewer is claimed. Public prior MDB aggregate counts and the earlier admission checks are known, but MDB signal/features/results must remain unused until freeze.

Every selected event retains source path, timestamp, native subtype and group for audit, none as model input. Preserve all eligibility exclusions, predictions and curves externally, with lightweight protocol/code/report in repository. Input manifests immutable; no accepted timing or Double-Bass files changed. No commit/push.

Success establishes only this pipeline's bounded oracle-onset discrimination, potentially followed by a single negative/positive rendered-to-acoustic transfer test. No autonomous event recognition, complete coverage, universal Ride identity, source separation, BeatReference or BPM. A failed transfer stops the task. New recording or new dataset search is not automatically authorized.
