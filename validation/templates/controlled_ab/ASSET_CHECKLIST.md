# Controlled A/B Asset Checklist

## Human-supplied scientific inputs

- [ ] Controlled Dataset, generation-record, provenance-revision, condition,
      Validation Item, Ground Truth, inventory, and experiment identities.
- [ ] Authoritative Condition A symbolic score.
- [ ] Authoritative Condition B symbolic score.
- [ ] Pre-analysis event-removal specification.
- [ ] Licensing status for every registered asset.

## Symbolic verification

- [ ] Shared authoritative meter and tempo.
- [ ] Shared instrumentation and total symbolic duration.
- [ ] Stable event identities.
- [ ] Every retained onset and duration is unchanged.
- [ ] Condition B contains no undeclared additions or substitutions.

## Audio verification

- [ ] Canonical and repeated PCM WAV for both conditions.
- [ ] Identical sample rate, bit depth, channels, and sample count.
- [ ] Common declared temporal origin.
- [ ] Leading, internal, and trailing silence preserved.
- [ ] Catalogue MP3 derivatives identified separately from WAV evidence.

## Provenance and execution

- [ ] All repository-relative paths and SHA-256 checksums recorded.
- [ ] Rendering and export configuration recorded.
- [ ] Unknown values explicitly recorded as `not specified`.
- [ ] Package validator succeeds before analysis.
- [ ] Blind identities assigned before execution.
- [ ] Ground Truth unavailable until both blind populations are frozen.
- [ ] Separate immutable analysis, Comparator, and Scientific Validation Record
      outputs preserved for each registered condition.
