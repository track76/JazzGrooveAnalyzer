# Purpose

This document defines the scientific semantics associated
with Metric Events within the Jazz Groove Analyzer.

A Metric Event is an observable rhythmic occurrence.

This document does not define algorithms.

It defines scientific meaning.

---

# Fundamental Principle

A Metric Event is never interpreted directly.

It represents an observable phenomenon extracted from
the musical signal.

Interpretation is performed only through explicitly
defined semantic rules.

# Observable Properties

Every Metric Event may expose observable properties.

Examples include:

- Absolute Time
- Metric Position
- Beat Association
- Offset
- Source
- Metric Cluster

These properties remain objective observations.

---

# Semantic Properties

Semantic properties describe the analytical role of
a Metric Event.

They are derived from observable evidence.

Examples include:

- Contribution Type
- Timing Behaviour
- Metric Role
- Ensemble Function

---

# Contribution Type

Contribution Type describes the participation of an event
in metric construction.

Initial vocabulary:

UNKNOWN

Future extensions may include additional contribution
categories once scientifically validated.

---

# Timing Behaviour

Timing Behaviour describes the temporal behaviour of
an event relative to its associated Beat Reference.

Initial vocabulary:

UNKNOWN

Future versions may define:

EARLY

ON_TIME

LATE

using experimentally validated thresholds.

---

# Metric Role

Metric Role describes the structural function of the event.

Initial vocabulary:

UNKNOWN

Future extensions shall be supported by musicological
evidence.

---

# Scientific Constraints

Semantic properties shall never modify the observable
properties of a Metric Event.

Observation always precedes interpretation.

---

# Rendering Independence

Semantic information belongs to the scientific model.

Renderers visualize semantic information.

Renderers never generate semantics.

---

# Future Evolution

Future versions may introduce additional semantic
dimensions including:

- Metric Stability
- Ensemble Cohesion
- Structural Importance
- Phrase Function
- Confidence Measures

provided they remain scientifically justified.
