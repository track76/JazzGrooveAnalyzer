# Optional recorded-data integration tests

The source-only public projection contains no licensed recordings, private datasets or physical reference. The real-audio source-understanding integration test is opt-in through JGA_RUN_LICENSED_AUDIO_TESTS=1; this switch is not a license, performer consent, scientific admission or authorization to obtain recordings. Verify exact input provenance, rights, permitted use and eligibility before enabling it. Never download/copy a recording merely to make a test pass.

Default public source checks report that integration as SKIPPED and retain the ordinary synthetic/unit/import tests. A skipped dependency is not a successful real-audio test or physical validation. The original missing-input failure is preserved in the preparation audit; the test body and its assertions are unchanged. BLOCKED_REFERENCE and conditional Phase B NOT_STARTED remain.
