# M8 Behaviour Distance

Status: DRAFT

==================================================

Objective

Define the quantitative distance between two
behavioural observations.

==================================================

Scientific Principle

Behavioural continuity is evaluated through the
distance between consecutive observations.

==================================================

Requirements

A behavioural distance shall be

- observable

- deterministic

- symmetric

- reproducible

==================================================

Purpose

The behavioural distance provides the mathematical
foundation for continuity analysis.

==================================================

Architectural Rule

Boundary detection depends on behavioural distance.

Behavioural distance is independent from
BehaviourState construction.
