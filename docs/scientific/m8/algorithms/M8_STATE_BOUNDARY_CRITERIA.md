# M8 State Boundary Criteria

Status: DRAFT

==================================================

Objective

Define when an observable behavioural variation is
sufficient to terminate one BehaviourState and begin
another.

==================================================

Scientific Principle

A BehaviourState boundary represents an observable
behavioural discontinuity.

It is never an arbitrary temporal partition.

==================================================

Necessary Conditions

At least one observable quantity exhibits a measurable
discontinuity.

The discontinuity must persist long enough to avoid
classification as local fluctuation.

==================================================

Sufficient Conditions

The observable discontinuity produces a coherent
behavioural change supported by multiple consecutive
observations.

==================================================

Non-Boundaries

The following SHALL NOT generate BehaviourState
boundaries.

- isolated outliers

- single noisy observations

- numerical instability

- missing observations

==================================================

Boundary Validation

Every detected boundary must satisfy

- reproducibility

- temporal consistency

- descriptor consistency

==================================================

Scientific Requirement

Boundary detection must remain completely explainable.

Every generated BehaviourState must expose the
observable evidence that produced its creation.

==================================================

Architectural Rule

BehaviourState boundaries are consequences of
observable evidence.

They are never assumptions.
