# M8 Boundary Evidence

Status: DRAFT

==================================================

Objective

Define the scientific representation of an observed
BehaviourState boundary before domain construction.

==================================================

Scientific Principle

BoundaryEvidence represents observable evidence of a
behavioural discontinuity.

It is not a BehaviourState.

==================================================

Produced By

BoundaryDetector

==================================================

Consumed By

BehaviourStateSegmenter

==================================================

Architectural Rule

BoundaryEvidence belongs to the scientific
representation layer.

BehaviourState belongs to the domain layer.
