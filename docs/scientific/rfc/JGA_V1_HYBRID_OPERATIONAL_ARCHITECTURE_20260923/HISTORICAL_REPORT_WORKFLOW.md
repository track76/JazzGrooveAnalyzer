# Frozen v1 historical-report workflow

Operational contract: [PI decision](PI_OPERATIONAL_DECISION.md). Method evidence, original paths, hashes, availability and preserved compact provenance: [authority references](AUTHORITY_REFERENCES.json).

1. Prepare the PI-reviewed batch: recording identities, exact asset hashes, rights/provenance, v1 scope, independently supported form boundaries and excluded endings. Do not select regions using favorable onset results. Record unknown form labels rather than inventing them.
2. Verify source and reused artifacts; preserve decoder/sample-rate/channel/PCM lineage and timestamp origin. Reuse exact frozen full-mix PLP reference and native/source evidence where applicable. For new recordings use the adopted frozen configurations through existing tooling; missing assets/configuration or unsupported conditions require review, not model search.
3. Preserve full-mix native event IDs, timestamps and qualified source-support records. Keep ADTOF/MuScriptor and inherited Bass-link/model dependencies explicit. No universal Bass identity or component-specific Drum identity is presumed.
4. Where useful, reuse valid authorized Demucs stems or generate through the existing pinned path. Preserve all derived-asset hashes and lineage; separator input is the original full mix. Analyze Bass/Drums using the same qualified detector/preparation. No stem-derived ruler, tuning or source separation treated as truth.
5. Freeze observations and apply the adopted matching rule. Keep all edges, unmatched and ambiguous cases. Attach separator source hypotheses to compatible full-mix events without modifying original source-state evidence or timestamps. Retain unmatched stem observations separately. Never convert shared Dual to two events at one coordinate.
6. Freeze the per-event provenance layer before interpretation: source asset/hash, event ID, native timestamp, original support, complementary support/evidence IDs, matching state, chosen timestamp origin, uncertainty status, quarter/cell ID and selection role. Provenance categories are not numerical confidence scores. This describes required report information, not a new implemented schema.
7. Produce both preserved quarter views using the same full-mix PLP ruler and exact midpoint/tie/EMPTY/no-reuse rules. Keep full-mix-primary and stem-only distributions identifiable and separate; do not inflate counts with shared markers. Preserve gray source-shaped context.
8. Report coverage, unknown/ambiguous/abstention counts, signed offsets, descriptive statistics and section comparisons with explicit denominators, timestamp semantics and limitations. Pair statistics require distinct supported observations. No invented ON threshold; no performer-intention or physical-attack claims from marker geometry.
9. Render existing whole-performance and established zoom styles. Label raw BPM lattice effects. Preserve source/provenance distinctions, EMPTY and all context. Report adverse or insufficient observations, rather than improving the model within a corpus analysis.
10. Validate source/parent hashes, timestamp preservation, matching and cell assignments, no reuse/borrowing/snapping, source states, complete context, graphics and section provenance. Freeze report tables/configuration/figures/limitations and exact parent lineage; submit for PI review. Commit/publication/backup follow the separately applicable authorization and established procedures.

The next batch has not been selected, analyzed or executed by this architecture closure. The Exactly Like You findings do not establish corpus-wide accuracy. Material operational blockers are reported to PI; they do not authorize automatic methodological work.
