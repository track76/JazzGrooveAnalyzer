# G-013 — Scientific Coordinate System

Status: APPROVED

Layer: Representation

Depends on:

- G-009 Metric Point Semantics
- G-010 Metric Geometry
- G-011 Geometric Transformations
- G-012 Metric Point Projection

---

# 1. Purpose

This document defines the scientific coordinate system adopted by the Representation Layer.

The coordinate system is a mathematical abstraction used exclusively to represent observable metric behaviour.

It is not a graphical space.

It is not a rendering space.

It is not a physical space.

Its sole purpose is to preserve scientific information generated by the Domain Layer.

---

# 2. Architectural Position

The coordinate system belongs exclusively to the Representation Layer.

Audio
    ↓
Domain
    ↓
Representation
    ↓
Visualization

Neither the Domain Layer nor the Visualization Layer may define or alter the semantics of this coordinate system.

---

# 3. Scientific Principle

Coordinates represent scientific properties only.

Coordinates never represent:

- pixels;
- screen positions;
- graphical objects;
- user interface elements;
- rendering primitives.

A coordinate exists exclusively because an observable scientific fact exists.

---

# 4. Coordinate Space

The Representation Layer defines an abstract mathematical coordinate space.

This space shall always be:

- deterministic;
- reproducible;
- renderer independent;
- platform independent;
- visualization independent.

Once generated, coordinates are immutable.

---

# 5. Origin

The origin of the coordinate system is a purely mathematical reference.

It does not correspond to:

- the beginning of the recording;
- the first beat;
- the first pulse;
- the first Elementary Metric Event;
- any musical event.

The origin carries no musical meaning.

---

# 6. Axes

The coordinate system defines one or more abstract axes.

At this stage, the axes intentionally have no scientific interpretation.

Their semantics will be introduced by G-014.

This separation preserves the independence between geometry and interpretation.

---

# 7. Scientific Units

Each axis shall define an explicit scientific unit.

Every unit must be:

- measurable;
- reproducible;
- comparable;
- renderer independent;
- visualization independent.

Graphical units are forbidden inside the Representation Layer.

---

# 8. Invariants

Every scientific coordinate system generated by JGA shall satisfy:

- determinism;
- reproducibility;
- mathematical stability;
- scientific traceability;
- renderer independence;
- implementation independence.

---

# 9. Scientific Traceability

Every coordinate shall preserve complete provenance.

The following chain must remain valid:

Observable Fact
        ↓
Metric Context
        ↓
Domain Object
        ↓
Representation Object
        ↓
Scientific Coordinate

No information may be lost throughout this transformation.

---

# 10. Visualization Independence

Visualization consumes scientific coordinates.

Visualization never creates coordinates.

Visualization never modifies coordinates.

Visualization never assigns scientific meaning.

Every graphical representation is therefore a projection of the Representation Layer and never part of the scientific model.

---

# 11. Forbidden Operations

The following operations are forbidden:

- introducing coordinates into the Domain Layer;
- assigning graphical semantics to coordinates;
- coupling coordinates to rendering frameworks;
- deriving scientific conclusions from graphical layouts;
- modifying scientific coordinates during visualization.

---

# 12. Architectural Consequences

This document establishes the following architectural rules:

1. Geometry belongs exclusively to the Representation Layer.

2. The Domain remains geometry-free.

3. Visualization depends on Representation.

4. Representation never depends on Visualization.

5. Every future scientific projection shall derive from this coordinate system without redefining its semantics.
