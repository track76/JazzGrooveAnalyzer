# G-004 — Metric Cluster Portrait Geometry

Status
    PROPOSED

Version
    1.0

Author
    Angelo Tracanna

------------------------------------------------------------
Purpose
------------------------------------------------------------

This document defines the geometric representation of a
Metric Cluster Portrait.

A Metric Cluster Portrait is the complete geometric
representation of one Metric Cluster.

It does not introduce new information.

It only exposes the observable geometric configuration of
the cluster.

------------------------------------------------------------
Scientific Principle
------------------------------------------------------------

The Portrait is a geometric representation.

It is not an analytical result.

It is not a musical interpretation.

It preserves every observable property of the Metric
Cluster.

------------------------------------------------------------
Portrait Structure
------------------------------------------------------------

Every Metric Cluster Portrait contains:

- one Beat Reference

- all Elementary Metric Events belonging to the cluster

- the observable temporal offsets of every Elementary
  Metric Event

------------------------------------------------------------
Geometric Representation
------------------------------------------------------------

The Beat Reference defines the geometric origin of the
portrait.

Every Elementary Metric Event is represented according to
its observable temporal position relative to the Beat
Reference.

The representation preserves complete observational
traceability.

------------------------------------------------------------
Scientific Integrity
------------------------------------------------------------

No graphical transformation shall modify:

- Beat Reference

- Elementary Metric Event identity

- temporal offset

- observable metric relationships

------------------------------------------------------------
Architectural Role
------------------------------------------------------------

The Metric Cluster Portrait constitutes the elementary
building block of the Metric Landscape.
