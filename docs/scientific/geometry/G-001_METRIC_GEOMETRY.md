# G-001 — Metric Geometry

Status
    PROPOSED

Version
    1.0

Author
    Angelo Tracanna

------------------------------------------------------------
Purpose
------------------------------------------------------------

Metric Geometry defines the scientific geometric model used
by the Jazz Groove Analyzer to represent observable metric
behaviour.

The purpose of Metric Geometry is not to introduce new
information.

Its purpose is to represent observable musical facts in a
geometrically consistent and completely traceable manner.

Every geometric entity shall correspond to an observable
scientific entity already defined by the JGA theoretical
model.

------------------------------------------------------------
Scientific Principle
------------------------------------------------------------

Metric Geometry is a representational layer.

It performs no interpretation.

It performs no inference.

It performs no classification.

It preserves the complete identity of every observable
entity throughout the entire analytical pipeline.

Every geometric transformation shall preserve the complete
scientific meaning of the represented observations.

------------------------------------------------------------
Observable Geometric Space
------------------------------------------------------------

The Metric Geometry of the Jazz Groove Analyzer represents
only observable metric phenomena.

It does not represent musical notation.

It does not represent performance quality.

It does not represent musical correctness.

It represents exclusively the observable relationships
between Elementary Metric Events and their Beat Reference.

------------------------------------------------------------
Geometric Identity
------------------------------------------------------------

Every Elementary Metric Event preserves its complete
identity inside the geometric representation.

No observable property may be discarded during geometric
representation.

Every geometric object shall remain fully traceable to the
scientific observation that generated it.

------------------------------------------------------------
Future Geometry
------------------------------------------------------------

Metric Geometry constitutes the theoretical foundation for:

• Metric Cluster Geometry

• Metric Cluster Portrait

• Metric Landscape

• Behaviour Geometry

These concepts are introduced in subsequent documents.
