# G-009 — Metric Point Semantics

---

## Purpose

This document formally defines the scientific meaning of a
MetricPoint.

MetricPoint is not a graphical coordinate.

It is a mathematical representation of one observable
state inside the Representation Layer.

---

## Scientific Principle

MetricPoint represents one position inside the metric
geometry of one musical performance.

The coordinates are scientific quantities.

They are never arbitrary visualization coordinates.

---

## Coordinate System

The coordinate system belongs to the Representation Layer.

Visualization software must never redefine
its scientific meaning.

---

## X Coordinate

Reserved.

The semantic definition will be introduced
after the complete geometric model has been
validated.

---

## Y Coordinate

Reserved.

The semantic definition will be introduced
after the complete geometric model has been
validated.

---

## Origin

The origin of the coordinate system will be
defined by the Representation Model.

It is not a visualization artifact.

---

## Units

Units are scientific quantities.

No graphical units are allowed.

---

## Invariants

MetricPoint is immutable.

MetricPoint preserves scientific traceability.

MetricPoint never contains inferred information.

MetricPoint never depends on visualization software.

MetricPoint belongs exclusively to the Representation Layer.
