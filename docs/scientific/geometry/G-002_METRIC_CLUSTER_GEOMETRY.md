# G-002 — Metric Cluster Geometry

Status
    PROPOSED

Version
    1.0

Author
    Angelo Tracanna

------------------------------------------------------------
Purpose
------------------------------------------------------------

This document defines the geometric representation of the
Metric Cluster.

A Metric Cluster is not considered a musical object.

It is considered an observable geometric configuration of
Elementary Metric Events sharing the same Beat Reference.

------------------------------------------------------------
Scientific Principle
------------------------------------------------------------

The Metric Cluster does not modify the Elementary Metric
Events it contains.

It only establishes their observable geometric
relationships.

Every Elementary Metric Event preserves its complete
scientific identity.

------------------------------------------------------------
Geometric Configuration
------------------------------------------------------------

A Metric Cluster is defined by:

- one Beat Reference

- a finite collection of Elementary Metric Events

- the observable temporal relationships between them

The Beat Reference constitutes the geometric origin of the
cluster.

------------------------------------------------------------
Observable Relations
------------------------------------------------------------

Every Elementary Metric Event is positioned according to its
observable temporal offset relative to the Beat Reference.

No normalization shall alter the observed measurements.

The geometry represents only observable metric relations.

------------------------------------------------------------
Cluster Integrity
------------------------------------------------------------

The Metric Cluster preserves:

- temporal ordering

- Beat Reference

- Elementary Metric Event identity

- complete traceability

No geometric operation may alter these properties.

------------------------------------------------------------
Architectural Role
------------------------------------------------------------

Metric Cluster Geometry provides the scientific foundation
for the Metric Cluster Portrait.

The Portrait is therefore a representation of an already
defined geometric object rather than a graphical
interpretation.
