# G-011 — Geometric Transformations

---

## Purpose

This document defines which geometric
transformations are scientifically valid
inside the Representation Layer.

Algorithms must comply with these rules.

---

## Fundamental Principle

Geometry preserves scientific meaning.

Transformations may change representation.

They never change scientific provenance.

---

## Allowed Transformations

Projection

Aggregation

Normalization

Scientific comparison

Distance computation

Temporal ordering

---

## Forbidden Transformations

Creation of inferred observations.

Modification of Domain semantics.

Loss of scientific traceability.

Visualization-dependent transformations.

Any transformation without mathematical
interpretation.

---

## Scientific Traceability

Every transformed object must preserve
its relationship with the originating
Domain objects.
