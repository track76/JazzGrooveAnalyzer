# G-003 — Beat Reference Geometry

Status
    PROPOSED

Version
    1.0

Author
    Angelo Tracanna

------------------------------------------------------------
Purpose
------------------------------------------------------------

This document defines the geometric role of the Beat
Reference within the Metric Geometry of the Jazz Groove
Analyzer.

The Beat Reference constitutes the geometric origin used to
represent the observable positions of Elementary Metric
Events.

------------------------------------------------------------
Scientific Principle
------------------------------------------------------------

The Beat Reference is a geometric reference.

It is not an interpreted beat.

It is not a theoretical beat.

It is not a musical truth.

It is exclusively the observable reference associated with
a Metric Cluster.

------------------------------------------------------------
Geometric Origin
------------------------------------------------------------

Each Metric Cluster owns exactly one Beat Reference.

Every Elementary Metric Event belonging to the cluster is
represented relative to this reference.

The Beat Reference therefore defines the local coordinate
system of the Metric Cluster.

------------------------------------------------------------
Observable Position
------------------------------------------------------------

The observable position of an Elementary Metric Event is
defined exclusively by its temporal offset from the Beat
Reference.

The Beat Reference introduces no additional information.

It only provides the coordinate origin required for
geometric representation.

------------------------------------------------------------
Representation Invariance
------------------------------------------------------------

Changing the graphical representation of the Beat Reference
shall never modify the scientific meaning of the observed
Metric Cluster.

The Beat Reference remains an invariant observational
entity.

------------------------------------------------------------
Architectural Role
------------------------------------------------------------

Beat Reference Geometry establishes the coordinate system
used by the Metric Cluster Portrait and every subsequent
scientific visualization.
