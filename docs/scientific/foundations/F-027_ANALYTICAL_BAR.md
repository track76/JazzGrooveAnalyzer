# F-027 — Analytical Bar

Status: DRAFT

## Purpose

Define the scientific meaning of the Analytical Bar representation.

The Analytical Bar is a reporting representation of a previously reconstructed
metric structure.

It does not perform musical inference.
It does not reconstruct metric information.
It only exposes scientific results already produced by the analysis pipeline.


## Scientific Position

The source of truth is:

ReconstructedMeasure

generated by:

Metric Reconstruction Layer


The transformation:

ReconstructedMeasure
        ↓
AnalyticalBar

is a representational translation.


## Architectural Principle

Reporting must never recreate scientific data.

The reporting layer receives validated domain objects and converts them into
human-readable representations.


## Input

Responsible input entity:

ReconstructedMeasure


A ReconstructedMeasure contains:

- metric position
- temporal boundaries
- beat references
- internal metric signature


## Output

The AnalyticalBar contains reporting-oriented information:

- bar number
- absolute start time
- absolute end time
- internal BPM
- metric signature
- analytical beats

## First Implementation Scope

The first implementation supports only metric structure.

Included:

- measure numbering
- temporal position
- BPM representation
- metric signature
- beat sequence


Excluded:

- instrument attribution
- timing offsets
- behavioural interpretation
- graphical score elements


## Future Extensions

Future analytical layers may add:

- instrument timing position
- millisecond offsets
- metric behaviour evolution
- comparison between measures
- graphical analytical notation
