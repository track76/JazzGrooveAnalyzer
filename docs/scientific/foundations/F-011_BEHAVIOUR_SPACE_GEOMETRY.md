# F-011 — Behaviour Space Geometry

Status

Draft

------------------------------------------------------------

Purpose

Scientific Behaviour Space is interpreted as a geometric
space whose trajectories represent observable rhythmic
behaviour.

The objective is to describe relationships between complete
behaviour trajectories.

------------------------------------------------------------

Primitive Objects

Behaviour Space

Behaviour Trajectory

Behaviour Point

Behaviour Distance Vector

------------------------------------------------------------

Geometric Relationships

Two Behaviour Spaces may be

• coincident

• parallel

• convergent

• divergent

• intersecting

• partially overlapping

------------------------------------------------------------

Trajectory Interpretation

Behaviour is represented as a continuous trajectory inside
Scientific Behaviour Space.

Distance is therefore evaluated between trajectories rather
than isolated points.

------------------------------------------------------------

Scientific Principle

JGA compares observable behaviour trajectories.

It never compares musicians.
