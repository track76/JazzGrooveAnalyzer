# F-013 — Behaviour Observation Protocol

Status

Draft

------------------------------------------------------------

Purpose

This document defines the scientific observation protocol
used by Jazz Groove Analyzer.

------------------------------------------------------------

Scientific Principle

Every observable behaviour shall be recorded.

No observation shall be discarded.

Diagnostics are performed after observation.

------------------------------------------------------------

Observation Sequence

Scientific Behaviour Space

↓

Behaviour Observation Frames

↓

Behaviour Diagnostics

↓

Behaviour Change Events

↓

Scientific Report

------------------------------------------------------------

Observation Rule

Identical consecutive observations remain scientific data.

Behaviour is continuously sampled regardless of variation.

------------------------------------------------------------

Diagnostic Rule

Diagnostics never replace observations.

Diagnostics enrich observations.

------------------------------------------------------------

Scientific Rule

No information loss is permitted.
