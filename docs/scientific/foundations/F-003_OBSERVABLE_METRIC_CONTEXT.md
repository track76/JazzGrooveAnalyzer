# F-003 — Observable Metric Context

Historical status clarification:

The list below is preserved as historical draft wording. Under current
authority, Observable Metric Context preserves temporal evidence, recurrence
and organization; it does not identify meter, tempo, ensemble Pulse or metric
level. See `F-031_HIERARCHICAL_METRIC_PERIODICITY.md`. Musical interpretation
belongs to the Domain under AD-008.

Before analysing individual events, the JGA builds the
Observable Metric Context.

The Observable Metric Context identifies:

- meter
- local tempo
- ensemble pulse
- metric contributors
- musical functions

All subsequent analysis depends on this context.
