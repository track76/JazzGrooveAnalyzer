# F-016 — Stable Region Scan

Status

Draft

------------------------------------------------------------

Purpose

Scan Behaviour Observation Frames and partition
them into consecutive Stable Regions.

------------------------------------------------------------

Scientific Principle

Each observation frame is compared with the
previous observation.

If all monitored quantities remain within
scientific tolerances, the current Stable Region
continues.

Otherwise the current Stable Region terminates
and a new region starts.
