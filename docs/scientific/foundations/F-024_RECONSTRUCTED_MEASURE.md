# F-024 — Reconstructed Measure

## Principle

A Reconstructed Measure is a scientific entity.

It is reconstructed exclusively from the
Internal Metric Timeline.

It is never inferred from a score.

A Reconstructed Measure is composed of:

- Beat References
- Metric Clusters
- Internal BPM
- Time Signature

The reporting layer shall consume
ReconstructedMeasure objects and shall
never reconstruct musical measures.
