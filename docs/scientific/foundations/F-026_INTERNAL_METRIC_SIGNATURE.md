# F-026 — Internal Metric Signature

## Principle

The Internal Metric Signature represents the reconstructed metric
organization of the ensemble.

It defines how Beat References are grouped into Reconstructed Measures.

The Internal Metric Signature is inferred from the analysed musical
performance and is never assumed from external notation.

## Purpose

It provides the scientific reference required for measure
reconstruction.
