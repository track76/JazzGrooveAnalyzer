# F-009 — Behaviour Distance

Status

Draft

------------------------------------------------------------

Purpose

Behaviour Distance defines the measurable difference between
two Scientific Behaviour Spaces.

The objective is to compare observable rhythmic behaviour.

No stylistic or aesthetic interpretation participates in the
measurement.

------------------------------------------------------------

Dual Representation

Every Behaviour Distance shall be represented in two domains.

Physical Domain

Unit

milliseconds

This represents the observable physical timing difference.

------------------------------------------------------------

Metric Domain

Unit

internal beat

This represents the observable timing difference expressed
relative to the reconstructed internal metric reference.

------------------------------------------------------------

Properties

Behaviour Distance shall satisfy

• non-negativity

• identity

• symmetry

• reproducibility

------------------------------------------------------------

Interpretation

Physical Distance

describes the observable temporal deviation.

Metric Distance

describes the observable deviation inside the reconstructed
metric system.

------------------------------------------------------------

Out of Scope

Behaviour Distance is not

• quality

• musical value

• artistic judgement

• stylistic ranking
