# F-010 — Behaviour Distance Vector

Status

Draft

------------------------------------------------------------

Purpose

Behaviour comparison cannot be represented by a single scalar.

Observable rhythmic behaviour is multidimensional.

Therefore JGA defines a Behaviour Distance Vector.

------------------------------------------------------------

Definition

D =

(
Physical,
Metric,
Stability,
Persistence,
Regularity
)

Each component represents one independent observable
dimension.

------------------------------------------------------------

Physical

Observable temporal distance.

Unit

milliseconds

------------------------------------------------------------

Metric

Distance measured in reconstructed internal beat units.

------------------------------------------------------------

Stability

Difference between stability behaviours.

------------------------------------------------------------

Persistence

Difference between persistence behaviours.

------------------------------------------------------------

Regularity

Difference between regularity behaviours.

------------------------------------------------------------

Interpretation

The complete Behaviour Distance is the vector itself.

Future scientific applications may derive scalar indicators
from this vector without replacing it.
