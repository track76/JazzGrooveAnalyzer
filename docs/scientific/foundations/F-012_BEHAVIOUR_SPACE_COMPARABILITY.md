# F-012 — Behaviour Space Comparability

Status

Draft

------------------------------------------------------------

Purpose

Before computing a Behaviour Distance, two Behaviour Spaces
must be scientifically comparable.

------------------------------------------------------------

Requirements

Both spaces shall

• belong to observable rhythmic behaviour

• contain at least one trajectory

• contain at least one Behaviour Point

------------------------------------------------------------

Output

Comparable

or

Not Comparable

------------------------------------------------------------

Scientific Principle

Distance is defined only between comparable Behaviour Spaces.
