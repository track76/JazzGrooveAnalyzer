# F-015 — Stable Region Detection

Status

Draft

------------------------------------------------------------

Purpose

Detect contiguous observation frames that exhibit
coherent metric behaviour.

------------------------------------------------------------

Definition

A Stable Region is a sequence of consecutive
Behaviour Observation Frames whose measured
parameters remain within configurable scientific
tolerances.
