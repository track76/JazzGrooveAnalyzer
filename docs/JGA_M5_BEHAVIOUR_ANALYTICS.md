# JGA M5 — Behaviour Analytics

Status: DRAFT

## Purpose

Behaviour Analytics is responsible for transforming the reconstructed
metric representation into a quantitative behavioural representation.

No interpretation is performed.

The layer only measures observable rhythmic behaviour.

## Input

- EnsembleProfile
- InternalMetricTimeline
- ReconstructedMeasureCollection

## Output

- BehaviourObservationCollection
- BehaviourProfile
- DescriptorSet
- BehaviourAnalytics
- AnalyticalStructure

## Scientific Principles

1. Deterministic
2. Reproducible
3. Observable
4. Representation-preserving
5. Theory-driven

## Non Goals

Behaviour Analytics never:

- classifies musical styles
- evaluates performers
- infers intentions
- generates aesthetic judgments

Those belong to future milestones.
