# Purpose

This document defines the first semantic rule of the
Jazz Groove Analyzer.

Timing Behaviour describes the temporal position of a
Metric Event relative to its Beat Reference.

---

# Observable Quantity

Timing Behaviour is computed exclusively from:

offset_ms

No additional musical interpretation is introduced.

---

# Semantic Categories

ANTICIPATING

The event occurs before the Beat Reference.

CENTERED

The event is sufficiently close to the Beat Reference.

DELAYING

The event occurs after the Beat Reference.

UNKNOWN

Timing behaviour cannot yet be determined.

---

# Scientific Principle

Timing Behaviour is derived from observation.

It is never inferred by graphical rendering.
