## v0.3.0-alpha — First Scientifically Usable Release

The authoritative release lineage is the certified bootstrap and Git tag
history; the older headings above are historical development notes, not
release-version authority.

This bounded alpha release provides the provenance-bearing canonical workflow
from explicit checksum-bound analytical sources through unchanged JGA
observations, AD-037 EME, AD-038 neutral Drum-relative geometry, AD-040
RhythmSectionTimingProfile, and deterministic
`JGA_RHYTHM_SECTION_TIMING_REPORT_V1` JSON.

Python package metadata uses the PEP 440 equivalent `0.3.0a0`. The release does
not add autonomous musical interpretation, calibration correction, automatic
roles, or external trackers.
